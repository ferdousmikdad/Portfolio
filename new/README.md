# 🧠 Project: macOS-Inspired Portfolio Redesign

## 1. Project Vision
I want to completely rebuild my portfolio from scratch with a fresh concept inspired by macOS Tahoe 26.4.

The goal is to create a highly interactive, OS-like web experience where users feel like they are navigating a desktop environment rather than a traditional website.

## 3. Window System (Core UI Concept)

All sections behave like macOS-style windows.

### Features:
- Each section = window UI
- Top-left controls:
  - 🔴 Close
  - 🟡 Minimize
  - 🟢 Maximize
- Consistent macOS-inspired design across all components

---

## 4. Window Behavior Logic

### 🗂 Minimize System
- Minimized windows go to a Dock/Trash system
- On hover:
  - Preview windows appear side-by-side
- Users can restore windows from preview

## 7. Menu Bar (Dock System)

### 📍 Position:
- Bottom of the screen

### 🎯 Inspiration:
- macOS Dock + Dynamic Island

### Structure:
- Left: `me-icon.svg`
- Right: `menu-short.svg`
- Center: Active page name

### Behavior:
- Click menu icon OR press:
  - Cmd + F / Ctrl + F
- Expands into full menu window

### Menu Window:
- All menu items include:
  - Icons
  - Shortcut labels (e.g. Shift + H)
- Selected menu appears in dock center
